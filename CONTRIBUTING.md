# Contributing

Start with a small issue describing the user problem. For UI changes, show desktop and narrow mobile screenshots with fictional data. Keep the five primary tabs and the single map; add details next to the selected player or location.

Run the relevant checks in the README. Add tests for meaningful behavior or regressions, not markup snapshots. Never test mutations against a private live world. The integration test is deliberately confined to the isolated loopback installation.

Do not add secrets, worlds, downloaded plugin/client binaries or third-party texture packs. Source changes must be compatible with GPL-3.0-or-later; identify third-party material and its license.

Performance claims should include hardware, sample size, workload and limitations. Do not advertise an alpha feature as available before it works and is documented.
